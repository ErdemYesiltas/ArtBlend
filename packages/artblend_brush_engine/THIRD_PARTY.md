# Native dependencies

Pinned upstream C sources and headers, with generated/configuration headers added for Apple and Android Clang targets. No GLib, gettext or OpenMP dependency. json-c pointer/patch extensions are not compiled.

- libmypaint 1.6.1: https://github.com/mypaint/libmypaint/tree/2768251dacce3939136c839aeca413f4aa4241d0 — ISC; see vendor/libmypaint/COPYING.
- json-c 0.19: https://github.com/json-c/json-c/tree/aa716cd8d663c976b99b0f30f102ee1d8ef63146 — MIT; see vendor/json-c/COPYING.

The two brush setting headers are generated by the included upstream generate.py and brushsettings.json. Configuration headers are maintained by ArtBlend; no network access is required during builds. MyPaint pixel tiles use premultiplied fixed-point RGBA (1.0 = 32768).

libmypaint also contains Paul Mineiro’s fastapprox headers under BSD-3-Clause. Their full notices remain in vendor/libmypaint/fastapprox/*.h and must accompany binary distributions.

## Local patch

`patches/libmypaint-bounded-input.patch` records three changes: compute the random sampling threshold in double precision to avoid converting rounded INT_MAX+1 to int; clamp the interpolation fraction and residual time to prevent negative rounding noise; return -1 when a single input would exceed 4096 dabs or has a non-finite dab count. The adapter treats this as a failed surface; partial output cannot be exported. These changes preserve upstream license notices.

The five .myb test fixtures in test/fixtures are copied from the same pinned libmypaint tests/brushes directory and remain covered by its source license.

The ArtBlend app ships two of them, `charcoal.myb` and `modelling.myb`, as built-in brushes (minified into `apps/studio/lib/domain/builtin_mypaint_presets.dart`); they stay under the same libmypaint ISC notice that the app's LicenseRegistry already carries.

## Adapter behavior

`ab_brush_configure` overrides radius and HSV color, and multiplies the preset's own `opaque` base value by the requested opacity. It leaves `opaque_multiply` untouched, because MyPaint presets usually carry their pressure-to-opacity curve there (0.0.1 replaced its base value, which made pressure curves such as charcoal's saturate to full opacity).
